# TATHVA imagery

Drop optimized client-supplied assets here, then set their paths in
`config/siteConfig.js` under `images`:

- `tathva-logo.png`      -> images.logo
- `tathva-boutique.jpg`  -> images.boutique (hero + boutique section)
- category photos        -> images.sarees / suits / kurtis / indoWestern / lehengas

Optimize before adding (aim for < 300 KB for hero, < 150 KB for others).
Until then, the site renders a CSS-only composition.
